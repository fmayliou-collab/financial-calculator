TIME VALUE OF MONEY
TVM 操作：輸入數值 → 按 N、I/Y、PV、PMT 或 FV 儲存。要算未知數時，按 CPT，再按該 TVM 鍵。
例：10,000 元、8%、3 年的終值：3 N → 8 I/Y → 10000 +/− PV → 0 PMT → CPT FV。
I/Y 直接輸入百分比，例如 8 代表 8%。正負號表示現金流方向。END/BGN 可切換普通年金與期初年金。CE/C 清除目前輸入；CLR TVM 清除全部 TVM 資料。
